# project/codeStyle.md

## Назначение

Этот документ фиксирует optional роль `project/codeStyle.md` внутри [`project-context-entry-system`](./project-context-entry-system.md).

## Когда файл нужен

`Project/codeStyle.md` стоит materialize-ить, когда проекту действительно нужен отдельный durable coding style layer.

Если проект маленький или code style очевиден из stack baseline, этот файл можно не создавать на старте.

## Что должен описывать файл

- language rules across layers;
- project-specific coding conventions;
- authoring conventions для code-adjacent artifacts.
