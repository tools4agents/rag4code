# project/repository-map.md

## Назначение

Этот документ фиксирует optional роль `project/repository-map.md` внутри [`project-context-entry-system`](./project-context-entry-system.md).

## Когда файл нужен

`Project/repository-map.md` нужен, когда repository уже достаточно вырос и агенту полезна отдельная top-level navigation map.

## Что должен описывать файл

- top-level areas репозитория;
- navigation hints по областям;
- links на entry points relevant layers.

## Что не должен описывать файл

- git ownership details во всех деталях;
- architecture SoT;
- execution status.
