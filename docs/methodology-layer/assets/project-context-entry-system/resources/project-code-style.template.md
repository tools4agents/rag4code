# Code Style

## Назначение

Этот файл фиксирует project-specific coding style и authoring conventions.

## Базовые правила

- Основной язык реализации — <language>.
- Package and environment workflow строятся вокруг `<tool>`.

## Язык в разных слоях

- Код, identifiers, docstrings, code comments и commit messages пиши на английском языке.
- Документацию проекта пиши на русском языке.

## Стиль проектирования

- Предпочитай explicit contracts и explainable boundaries.
- Не смешивай architecture rationale и execution notes.
