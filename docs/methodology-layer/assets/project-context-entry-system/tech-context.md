# project/techContext.md

## Назначение

Этот документ фиксирует роль `project/techContext.md` внутри [`project-context-entry-system`](./project-context-entry-system.md).

## Что должен описывать файл

- primary language и package manager baseline;
- environment assumptions;
- main technical areas репозитория;
- external dependencies и conventions, важные для чтения проекта.

## Что не должен описывать файл

- full architecture SoT;
- task-level implementation plan;
- secret storage details.
