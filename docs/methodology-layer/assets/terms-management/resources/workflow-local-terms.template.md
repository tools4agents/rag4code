# Terms: `<workflow-pack-name>`

## Назначение

Этот файл фиксирует workflow-local terms для `<workflow-pack-name>`, чтобы `workflow.md`, `STEP.md` и `SKILL.md` использовали одни и те же термины без повторного переопределения.

Используй такую страницу только для терминов, которые:
- специфичны для этого workflow-pack;
- часто переиспользуются между несколькими workflow docs;
- не должны подниматься в project-wide glossary.

## Правило использования

- При первом значимом использовании термина в `workflow.md`, `STEP.md` или `SKILL.md` давай ссылку на эту страницу или на конкретный term heading.
- Не дублируй полное определение термина в каждом step doc.
- Если термин перестает быть workflow-local и становится project-wide, перенеси его определение в `docs/terms/`.
