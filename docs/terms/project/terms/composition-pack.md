# composition pack

> Status: Draft  
> Scope: project-specific term for HyperGraph asset taxonomy  
> Related: `../terms_map.md`

`Composition pack` — это publishable совместимый набор assets разных типов, который можно подключить как готовый методологический стек.

Он может включать:

- `knowledge-lifecycle asset`;
- `task-management-system asset`;
- `terms-management-system asset`;
- `methodology asset`;
- `rules pack`;
- `skills pack`;
- другие совместимые reusable assets.

`Composition pack` нужен для свободной сборки и публикации opinionated methodology stacks.
