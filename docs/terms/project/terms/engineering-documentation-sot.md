# engineering-documentation-sot

> Status: Draft  
> Scope: project-specific term for knowledge lifecycle layers  
> Related: `../terms_map.md`

`Engineering Documentation SoT` — это канонический инженерный Source of Truth проекта.

Он хранит архитектуру, glossary, contracts, ADR и другие long-lived engineering documents, на которые должны опираться разработчики и агенты.

В текущем baseline этот слой соответствует `docs/`.
