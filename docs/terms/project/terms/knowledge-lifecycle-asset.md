# knowledge-lifecycle asset

> Status: Draft  
> Scope: project-specific term for HyperGraph asset taxonomy  
> Related: `../terms_map.md`

`Knowledge-lifecycle asset` — это asset type, который задает lifecycle знания в проекте.

Он определяет:

- где рождается новое знание;
- где оно становится каноническим;
- где оно публикуется для внешнего потребления.

Этот asset type не задает сам по себе task storage, glossary layout или process semantics конкретной methodology.

Первый concrete example этого типа в HyperGraph — `document-driven-development`.
