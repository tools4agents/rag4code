# operational-documentation-layer

> Status: Draft  
> Scope: project-specific term for knowledge lifecycle layers  
> Related: `../terms_map.md`

`Operational Documentation Layer` — это временный operational слой, в котором рождается, уточняется и проверяется новое знание до его канонизации.

Типичные artifacts этого слоя: ideas, plans, tasks, research, discussion, review, open questions, white spots и spike reports.

В текущем baseline этот слой соответствует `operational_scope/`.
