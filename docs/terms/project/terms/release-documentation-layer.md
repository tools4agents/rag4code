# release-documentation-layer

> Status: Draft  
> Scope: project-specific term for knowledge lifecycle layers  
> Related: `../terms_map.md`

`Release Documentation Layer` — это release-ready documentation для внешнего потребления.

Он предназначен для пользователей, интеграторов и контрибьюторов и может materialize в publishable docs system вроде Docusaurus.
