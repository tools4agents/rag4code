# spike-experiment

> Status: Draft  
> Scope: project-specific term for operational validation activity  
> Related: `../terms-map.md`, [`spike-report`](./spike-report.md), [`spike-experiment-evidence-pattern.md`](../../../methodology-layer/patterns/spike-experiment-evidence-pattern.md)

`Spike experiment` — это небольшая bounded validation activity в форме PoC, probe или кодового эксперимента, которая проводится для проверки гипотезы, снятия неопределенности или выбора технического направления и обычно завершается артефактом [`spike-report`](./spike-report.md).

Для spikes, где важны runtime observations и machine-readable evidence artifacts, рекомендуется использовать [`spike-experiment-evidence-pattern.md`](../../../methodology-layer/patterns/spike-experiment-evidence-pattern.md).
