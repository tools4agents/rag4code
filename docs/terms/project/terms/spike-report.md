# spike-report

> Status: Draft  
> Scope: project-specific term for operational validation artifacts  
> Related: `../terms_map.md`

`Spike report` — это operational artifact, который фиксирует результат небольшого PoC или кодового эксперимента, проведенного для проверки гипотезы, снятия неопределенности или выбора технического направления.
