# spike-report

> Status: Draft  
> Scope: project-specific term for operational validation artifacts  
> Related: `../terms-map.md`, [`spike-experiment`](./spike-experiment.md)

`Spike report` — это operational artifact, который фиксирует результат [`spike-experiment`](./spike-experiment.md): небольшого PoC, probe или кодового эксперимента, проведенного для проверки гипотезы, снятия неопределенности или выбора технического направления.
