# task-management-system asset

> Status: Draft  
> Scope: project-specific term for HyperGraph asset taxonomy  
> Related: `../terms_map.md`

`Task-management-system asset` — это asset type, который задает систему хранения, индексации и управления task artifacts.

Он определяет:

- где живут tasks;
- как устроен task index;
- как фиксируются status, handoff и execution context.

Этот asset type не обязан задавать lifecycle знания в проекте и может использоваться вместе с разными `knowledge-lifecycle assets`.
