# testing-system asset

> Status: Draft  
> Scope: project-specific term for HyperGraph asset taxonomy  
> Related: `../terms_map.md`

`Testing-system asset` - это asset type, который задает систему хранения, индексации и traceability для test documentation и links к test implementation.

Он определяет:
- где живет test index;
- как устроены suite pages;
- как задаются stable identifiers для suites и test cases;
- как documentation связывается с test implementation.

Этот asset type не подменяет `knowledge-lifecycle asset` и не задает общий process model разработки. Он отвечает только за testing-oriented documentation and traceability system.
