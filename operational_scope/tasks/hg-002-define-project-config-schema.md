# Task: Define project config schema for `.hypergraph/project.toml`

## Контекст

Для первой итерации HyperGraph уже принято product/system-level решение: project-local config хранится в TOML-файле:

```text
<project-root>/.hypergraph/project.toml
```

Связанные durable SoT artifacts:

- [`project-config-format.md`](../../docs/system_design/project-config-format.md);
- [`project-identity-and-registry.md`](../../docs/system_design/project-identity-and-registry.md);
- [`project-model.md`](../../docs/system_design/project-model.md);
- [`project-key`](../../docs/terms/project/terms/project-key.md);
- [`project-config`](../../docs/terms/project/terms/project-config.md).

Следующий unresolved design point — определить минимальную schema `.hypergraph/project.toml` для MVP без преждевременного freezing future capabilities.

## Цель

Спроектировать минимальную и расширяемую schema `.hypergraph/project.toml`, достаточную для `project init`, `project register`, scan/indexing configuration и shared project identity.

## Scope

Включить:

- required fields;
- optional fields;
- `project_key` format and validation rules;
- `display_name` / description policy;
- `[scan] exclude` syntax;
- `.git` hard-exclude behavior outside config;
- placeholders generated by `project init`;
- distinction between shared project-local config and machine-local settings;
- reserved sections for future graph/indexing conventions if needed;
- examples of valid and invalid config.

## Non-scope

Не включать:

- registry record schema;
- database backend config schema;
- project database binding schema;
- credential storage policy;
- final CLI/MCP command contracts;
- implementation code;
- full validation library selection.

## Expected durable docs updates

Минимально обновить:

- [`docs/system_design/project-config-format.md`](../../docs/system_design/project-config-format.md)

При необходимости создать отдельный focused doc, если schema section станет слишком большой:

```text
docs/system_design/project-config-schema.md
```

Contract-level materialization можно отложить, если schema еще не готова стать formal contract.
